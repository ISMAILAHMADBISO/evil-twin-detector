Detection Methodology

EvilTwin Detector operates strictly defensively from the client side using the host computer's wireless adapter. Discovered access points are evaluated against an administrator-curated SQLite baseline of approved access points across five transparent rules:

  • Rule 1 (Authorised): Registered BSSID matching expected security configuration.
  • Rule 2 (Suspicious): Same SSID as an approved network, but advertised by an unregistered BSSID.
  • Rule 3 (Unknown): Unregistered access point that does not violate suspicious impersonation rules.
  • Rule 4 (Suspicious): Registered BSSID observed with an unexpected security configuration.
  • Rule 5 (Supporting Indicators): Signal strength (RSSI) and channel details displayed to support investigation without acting as sole proof.
